# ⌨️ 손가락 길잡이 — 타자(타법) 교정 시스템

> 손가락이 제자리를 찾도록, 키보드가 알려주고 화면이 기록한다.

한국코드페어 2026 · SW공모전 **초등부** 출품작 (Physical Computing + SW).

기존 타자연습은 **어떤 *키*** 를 눌렀는지만 압니다. 이 작품은 아두이노 손가락 감지로
**어떤 *손가락*** 으로 눌렀는지까지 알아내, "올바른 운지율"이라는 새 지표로
**독수리 타법**을 잡아주는 통합 타자연습기입니다.

## 구성

```
typo-game/
├── webapp/                 # 웹 타자연습 앱 (HTML + CSS + 클래식 JS, Web Serial)
│   ├── index.html          #   마크업 + 스크립트 로드
│   ├── css/styles.css      #   스타일 (글래스/그라데이션 UI)
│   └── js/
│       ├── config.js       #   운지표 · 연습문장 · 키보드/색 데이터
│       ├── hands.js        #   양손 SVG 그림 (빛나는 손가락 안내)
│       ├── keyboard.js     #   화면 키보드 + 하이라이트
│       ├── serial.js       #   Web Serial (아두이노 USB 직접 수신)
│       ├── history.js      #   localStorage 기록 + 추이 그래프(SVG)
│       └── app.js          #   연습 로직 · 정확도/운지율/타수 측정 · 조립
└── arduino/
    └── finger_guide.ino    # 손가락×키 구역 매트릭스 스캔 + LED·부저 펌웨어
```

## 실행

### 웹앱
1. **크롬 또는 엣지**로 `webapp/index.html` 열기 (Web Serial은 크롬 계열만 지원)
   - 로컬 서버 권장: `cd webapp && python3 -m http.server 8000` → http://localhost:8000
2. **데모 모드** 체크박스로 아두이노 없이 손가락 시뮬레이션 + 운지율 확인 가능
3. 아두이노 사용 시: USB 연결 → [아두이노 연결] → 포트 선택 후 화면 문장을 따라 타이핑

> 정확도·타수는 아두이노 없이도 측정됩니다. **올바른 운지율**은 아두이노(또는 데모 모드)에서 측정됩니다.

### 아두이노
1. Arduino IDE에서 `arduino/finger_guide.ino` 열기 → Uno(호환) 선택 → 업로드
2. 시리얼 모니터(9600bps)에서 `READY`, 접촉 시 `L2`·`R3` 같은 손가락 ID 출력 확인
3. 배선 예: ROW(손가락8)=D2~D9, COL(키 구역)=A0~A5(각 10kΩ 풀다운→GND), 초록 LED=D12 / 빨강 LED=D11 / 부저=D10

## 핵심 원리

- **매트릭스 스캔:** 손가락 = ROW(출력 핀, 하나씩 HIGH), 키 구역 = COL(입력 핀).
  손가락 구리패드가 키 구리패드에 닿으면 그 교차점이 ON → **(어느 손가락 × 어느 키구역)** 동시 확정.
- **데이터 합치기:** 웹앱이 ① 키보드 입력(어떤 키·타이밍·정확도) + ② 아두이노(어떤 손가락)을
  같은 타이밍으로 매칭(기본 0.6초 창) → "F를 왼손검지로 정확히" 식으로 판정.
- **새 지표 — 올바른 운지율(%)** : 약한 손가락·자주 틀리는 키를 기록해 습관 개선을 시각화.

## 기술 메모

- 외부 CDN·폰트·라이브러리 없음(시스템 폰트만). 클래식 스크립트 + `window.FG` 네임스페이스로 `file://`에서도 동작.
- `prefers-reduced-motion` 지원, 색+글자 이중 코딩(색약/저학년 접근성).
- MVP 범위: 소문자·공백 위주. 대문자/특수문자/한글, 엄지 채널, 손모양 고도화는 2단계.
